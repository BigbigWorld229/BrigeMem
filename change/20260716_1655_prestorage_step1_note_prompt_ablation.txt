MemWeave PreStorage Step 1 Note Prompt 消融变更记录
====================================================

时间：2026-07-16 16:55 CST

一、配置文件

1. ablation_config.json
   - 在现有 components 对象中新增布尔项 prestorage_step1_use_existing_note_prompt，默认 true。
   - true：继续使用原有 STEP1_NOTE_PROMPT。
   - false：使用新增的禁止代词、禁止相对时间并要求 lossless_restatement 为独立完整句子的 Prompt。
   - 继续沿用可扩展的 components 布尔项结构。

2. ablation_config.py
   - 新增 PRESTORAGE_STEP1_EXISTING_NOTE_PROMPT 常量，值为
     prestorage_step1_use_existing_note_prompt。
   - 现有配置结构和 JSON boolean 严格校验逻辑不变。

二、启动脚本

1. hpc/memweave-qwen25-locomo.sh
   - 新增 STEP1_NOTE_PROMPT_COMPONENT，并检查配置中必须存在对应布尔项。
   - 继续使用通用 components 遍历，在运行开始时打印包括新开关在内的全部消融项及布尔值。
   - 配置路径继续通过 --ablation-config 传给 Python driver。

三、必要代码

1. prestorage_pipeline.py
   - 保留 STEP1_NOTE_PROMPT 原文不变。
   - 新增 STEP1_NOTE_PROMPT_NO_PRONOUNS_RELATIVE_TIME，内容严格对应需求给出的替代 Prompt。
   - PreStoragePipeline.__init__() 新增 use_existing_step1_note_prompt 参数，默认 true；根据该参数
     将 self.step1_note_prompt 设为原模板或替代模板。
   - PreStoragePipeline._extract_step1_metadata() 改为展开 self.step1_note_prompt；LLM operation、
     temperature、JSON 解析、缺失字段回退及返回结构均未修改。

2. hpc/memweave_qwen25_3b_locomo_driver.py
   - 导入 PRESTORAGE_STEP1_EXISTING_NOTE_PROMPT。
   - main() 通过 AblationConfig.require() 读取新开关，并传入 PreStoragePipeline。
   - true 时继续使用原 turn_compressor.cache_tag()，保持现有缓存路径。
   - false 时在缓存标签追加 _step1_note_prompt_ablation，使 Step 1 JSONL、Step 2 派生结果、
     embedding 和 memory/retriever 缓存与原 Prompt 隔离，避免旧 Step 1 缓存掩盖替代 Prompt。

四、验证

1. python -m py_compile：配置加载器、prestorage pipeline、driver 和 eval 入口通过。
2. bash -n hpc/memweave-qwen25-locomo.sh：通过。
3. 默认配置解析成功并输出五个布尔消融项。
4. premem Conda 环境下的无模型 Prompt 选择测试通过：
   - true 实际展开 STEP1_NOTE_PROMPT；
   - false 实际展开 STEP1_NOTE_PROMPT_NO_PRONOUNS_RELATIVE_TIME；
   - {{$message}} 被替换为传入消息，替代模板包含禁止代词、相对时间和 lossless_restatement 条款；
   - 两侧的 LLM operation、temperature、metadata 解析结构一致，STEP2_REASONING_PROMPT 未改变。
